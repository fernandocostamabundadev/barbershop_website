# Barbershop

Website responsivo de uma barbearia, desenvolvido com HTML, CSS e JavaScript sem dependências de instalação.

## Funcionalidades

- Navegação adaptada a telemóveis, com suporte para teclado.
- Animações suaves de entrada e interação, respeitando a preferência por movimento reduzido.
- Portefólio, serviços, equipa e chamada para contacto por e-mail.
- Imagens com carregamento diferido e estrutura acessível.

## Pré-visualização

Abra o ficheiro `index.html` num navegador. O formulário de contacto é demonstrativo e o botão de e-mail abre um rascunho; não confirma marcações.

Este projeto foi inspirado no tutorial [Responsive Barbershop Website](https://youtu.be/7zjrsmMYPyY), de [Bedimcode](https://www.youtube.com/@Bedimcode).
